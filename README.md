# Abid Hanan - DevRel

Bilingual watercolor portfolio, built with Next.js 16 and React 19.

## Development

```sh
npm ci
npm run dev
```

Before publishing:

```sh
npm run lint
npm run build
npm audit --omit=dev
```

Production uses the existing Vercel project `ahawi-portofolio`, at
https://www.abidhanan.my.id. The GitHub production branch is `master`.

## Images

Photographs, certificates, and raster logos use WebP. The social sharing image
uses a compact 1200 × 630 JPEG, and the browser icon retains PNG. Images below the fold load
lazily; the central hero image is preloaded.

`npm run images:optimize` converts new JPEGs (and `logo-ush.png`) in `public` to
WebP. Update their references before removing the originals. Certificates retain
a larger resolution for readable text.

## Cloudflare asset CDN

The CDN configuration is prepared but activation requires access to Cloudflare.
Until `NEXT_PUBLIC_ASSET_BASE_URL` is configured, the website continues to use
Vercel's image optimization and serves public assets locally.

```sh
npx wrangler login
npm run cdn:deploy
```

This deploys assets and responsive WebP variants from `.cloudflare/assets` to
the `abidhanan-portfolio-cdn` Worker. Generated files are ignored by Git and
Vercel uploads. Set `NEXT_PUBLIC_ASSET_BASE_URL` to the actual HTTPS Worker URL
in Vercel's production environment. Redeploy the application only after
confirming the CDN serves the assets successfully.

Redeploy the CDN before deploying new or modified images. `cdn:prepare` refreshes
per-file version hashes and responsive variants. Asset URLs include a version
query to refresh browser caches when a file changes.

This setup serves media through Cloudflare without changing the domain's
nameservers or application hosting.

## SEO and accessibility

Metadata includes the page title, description, canonical URL, Open Graph,
Twitter cards, crawler rules, viewport, theme color, and Person/ProfilePage
structured data. `/robots.txt` and `/sitemap.xml` are generated by Next.js.
Sections have named headings, tools use semantic lists, and navigation exposes
its mobile expanded state. Keyboard users can skip to the main content.
